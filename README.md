# WanderLuxe Travel Website (Separate HTML, CSS & JS Files)

This folder contains the multi-file frontend structure for **WanderLuxe**:

- `index.html` — Page structure, sections, modals, and layout markup
- `css/styles.css` — Custom CSS variables, hero styling, card transitions, and print styles
- `js/data.js` — Initial seed packages, hotels, photo gallery items, users, bookings, and reviews
- `js/app.js` — Search/filtering, booking calculators, itinerary builder, lightbox, reviews, contact form, and admin panel

## How to Run Locally
Because `index.html` loads `css/styles.css`, `js/data.js`, and `js/app.js`, keep all files in the same folder hierarchy and open `index.html` in any modern web browser (or serve via VS Code Live Server / `npx serve`).
