WanderLuxe
WanderLuxe is a travel booking website that helps users explore travel packages, estimate trip costs, and plan their journeys. It is built with HTML, CSS, and JavaScript.
Live Demo
Visit WanderLuxe
Features
- Browse, search, filter, and sort travel packages.
- View package details and manage a wishlist.
- Estimate hotel and flight costs.
- Create and manage travel itineraries.
- Register, log in, and view profile details.
- View gallery images and customer reviews.
- Use the admin panel to manage packages, bookings, and users.
- Save demo data in the browser using localStorage.
Built With
- HTML5
- CSS3
- JavaScript
- Tailwind CSS
- Lucide icons

Run Locally
1. Download or clone the project.
2. Open the project folder in VS Code.
3. Open index.html using the Live Server extension.
You can also run a local server from the project folder:
python -m http.server 8000
Then open http://localhost:8000 in your browser.

Important Note
WanderLuxe is a frontend demonstration project. User details, wishlist items, itineraries, and booking data are stored in the browser using localStorage. It does not process real payments, issue flight tickets, or confirm real hotel reservations.
Feel free to explore the project and customise it for your needs.
